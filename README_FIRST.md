## 🎯 Three Simple Steps to Deploy:

### **1️⃣ Create GitHub Repository** (2 minutes)
- Go to [github.com](https://github.com) and sign in
- Click **"+" → "New repository"**
- Name it: **`computer-vision-studio`**
- Make it **PUBLIC** ⚠️ (important for free hosting!)
- **Don't** add README or .gitignore (we already have them)
- Click **"Create repository"**

### **2️⃣ Push Your Code** (1 minute)
Open PowerShell and copy-paste these commands:

```bash
cd "C:\Users\Shreya Singh\Desktop\cv"
git remote add origin https://github.com/YOUR_USERNAME/computer-vision-studio.git
git branch -M main
git push -u origin main
```

⚠️ **Replace `YOUR_USERNAME` with your actual GitHub username!**

### **3️⃣ Deploy to Streamlit Cloud** (3 minutes)
- Go to [share.streamlit.io](https://share.streamlit.io)
- Sign in with GitHub
- Click **"New app"**
- Enter:
  - Repository: `YOUR_USERNAME/computer-vision-studio`
  - Branch: `main`
  - Main file: `app.py`
- Click **"Deploy!"**
- Wait 2-5 minutes ⏱️
- Get your public URL! 🎉
