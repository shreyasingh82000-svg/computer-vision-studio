## 🚀 **How to Use**

### **First Time**
1. Application opens with welcome message
2. Shows your student details
3. Click OK to start

### **Upload Image**
1. Click "📤 Upload Image" (or Ctrl+O)
2. Select any image
3. See it appear in both panels

### **Apply Operations**
1. Navigate through 6 tabs
2. Click operation buttons
3. See results instantly
4. Use Undo (Ctrl+Z) freely

### **Save Work**
1. Click "💾 Save Result" (or Ctrl+S)
2. Choose location and name
3. Done!
